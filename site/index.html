              About the project

              ShuttleDestiny is a personal machine learning project by Surya Ilamurugu. It started as a Random Forest that looked at three things: the last shot, where it landed, and the shot number. That version scored 43%.

              Version 2 adds real court positions for both players and the shuttle, converted from broadcast video into metres using each match's court mapping, plus the two earlier shots, the score and the receiving player. A gradient-boosted tree model learns from those inputs and reaches 46%, and it predicts rarer shots like rushes and wrist smashes far better than before.

              The trained trees are exported to a small file and evaluated in JavaScript, so predictions are instant and no server is needed.

              Built with

              Python, pandas, scikit-learn (HistGradientBoostingClassifier), plain HTML, CSS and JavaScript.

              Data

              ShuttleSet by Wang et al. (KDD 2023): stroke-level annotations of professional men's and women's singles matches from 2018 to 2021.
